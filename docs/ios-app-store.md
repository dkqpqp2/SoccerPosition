## 4. 설명 (4,000자 이내)

풋살·축구 팀 운영, 아직도 카톡방에서 하시나요?
스포츠팀매니저는 팀장·총무·팀원이 함께 쓰는 팀 관리 앱이에요.

■ 포지션 배정과 전술판
- 포메이션을 고르고 팀원을 끌어다 놓으면 포지션 배정 끝
- 전술판에 선수 위치와 움직임을 그려서 팀원과 공유

■ 경기 관리
- 경기 일정과 장소 등록, 지도에서 장소 찾기
- 참석·불참·미정을 버튼 한 번으로 응답, 참석 현황을 한눈에
- 경기 결과와 골·어시스트 기록, 팀 통계

■ 회비 관리
- 팀원별 납부 현황과 수입·지출 내역을 한눈에
- 미납자를 단체방에서 독촉하지 않아도 돼요

■ 투표와 소통
- 회식, 일정 같은 의견을 투표로 빠르게 결정
- 댓글로 의견을 나누고, 불쾌한 내용은 신고·차단

■ 유니폼 관리
- 하계·동계·조끼 등 팀원별 보유 현황 관리

■ 알림
- 투표, 회비 요청, 포지션 배정 소식을 푸시 알림으로 받아요.

■ 이런 분께 추천해요
- 팀장·총무로서 매번 엑셀과 단톡방으로 운영하는 분
- 내전 팀 짜기와 회비 정산이 번거로운 분
- 우리 팀 기록을 한곳에 모아 두고 싶은 분

Apple 또는 카카오 계정으로 바로 시작할 수 있고, 처음 로그인하면 팀이 자동으로 만들어져요.

## 6. 심사 메모 (App Review Information → Notes)

이 앱은 풋살·축구 팀 운영(팀원 관리, 포지션 배정, 경기 일정·참석, 회비, 투표)을 돕는 서비스입니다.

[로그인 방법]
- 로그인 화면에서 "Apple로 계속하기"를 누르면 심사자 본인의 Apple ID로 바로 가입·로그인할 수 있습니다. 별도 데모 계정은 필요하지 않습니다.
- 처음 로그인하면 "우리팀"이라는 팀이 자동으로 만들어지고, 로그인한 사람이 팀장이 됩니다.

[확인해 보실 기능]
1. 홈: 팀 현황과 다가오는 경기 / 경기 관리에서 경기를 만들고 참석 응답
2. 팀원 관리 → 팀원 추가 / 포지션 배정 → 포메이션에 팀원을 배치
3. 투표: 투표를 만들고 댓글 작성 (처음 작성할 때 커뮤니티 이용 규칙 동의 창이 뜹니다)
4. 마이페이지: 앱 알림 켜기/끄기, 내 유니폼 체크, 차단한 사용자 관리

[사용자 콘텐츠(Guideline 1.2)]
- 사진·댓글 옆의 "신고" 버튼으로 신고(사유 선택)와 작성자 차단이 가능하며, 신고·차단한 콘텐츠는 즉시 숨겨집니다.
- 처음 콘텐츠를 올릴 때 커뮤니티 이용 규칙 동의를 받습니다. 이용약관: https://www.soccerpositionmanagement.com/terms
- 신고는 24시간 안에 확인하고 조치합니다. 문의 및 신고 연락처: https://www.soccerpositionmanagement.com/support

[계정 삭제(Guideline 5.1.1(v))]
- 마이페이지 맨 아래 "회원 탈퇴"에서 앱 안에서 직접 삭제할 수 있으며, Apple로 가입한 경우 Apple 연결(토큰)도 함께 해제합니다.

[기타]
- 앱은 서비스 서버에서 화면을 불러오며, 푸시 알림(마이페이지에서 켜고 끌 수 있음)과 카메라·사진 보관함(팀 로고 사진) 등 기기 기능을 사용합니다.
- 결제나 구독은 없으며 모든 기능이 무료입니다.

## 7. 연령 등급 질문 가이드

질문 문구는 App Store Connect 화면 기준으로 달라질 수 있어요. 화면에 나오는 질문에 아래 방향으로 답하세요.

| 질문 | 답 |
|---|---|
| 폭력, 성적 콘텐츠, 도박, 약물 등 | 모두 "없음" |
| 사용자 생성 콘텐츠 (사진·댓글) | "있음" — 팀원끼리 사진과 댓글을 올림. 신고·차단 기능과 이용 규칙이 있음 |
| 제한 없는 웹 접근 | "아니요" (앱이 자체 서비스만 불러옴) |
| 결제·구독·광고 | 없음 |

사용자 생성 콘텐츠가 있으면 등급이 올라갈 수 있어요(보통 12+ 전후). 화면에서 계산된 등급을 그대로 받아들이세요.

## 10. 출시 전에 Apple Developer 사이트에서 켤 것

1. Identifiers → 앱 ID(`com.soccerpositionmanagement.app`)에서 **Push Notifications**와 **Sign in with Apple** 기능 켜기
2. Services ID 만들기(웹 로그인용), Sign in with Apple 키(.p8)와 APNs 키 만들기
3. App Store Connect에서 앱 만들기 → API 키를 Codemagic에 등록 → 빌드 → TestFlight → 심사 제출
