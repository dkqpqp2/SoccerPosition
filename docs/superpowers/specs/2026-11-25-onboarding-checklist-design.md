# 홈 "시작하기" 체크리스트 — 짧은 설계 (승인됨 2026-11-25)

## 의도와 이유
다른 팀을 끌어오는 것이 우선이다. 운영 데이터상 가입자 39명 중 경기·배정을 기록한 팀은 3곳뿐이고, 팀원이 있는 22개 팀 대부분이 1명짜리 빈 팀(기본 이름 "우리팀")이다.
현재 신규 안내는 "팀 이름을 바꾸세요" 배너 하나뿐이고 팀원 초대·첫 경기는 안내하지 않는다. 초대 버튼은 팀 카드 옆 작은 버튼(팀장 전용)이며 링크 복사만 된다.
(빈 팀이 생기는 진짜 이유가 이것인지는 확인되지 않은 추정이다.)

## 목표 / 비목표
- 목표: 새 팀장이 홈에서 팀원 초대 → 첫 경기 등록 → 포지션 배정까지 한 흐름으로 가게 한다.
- 비목표: DB 변경, 푸시 알림, 새 팀 샘플 데이터, 전체 화면 마법사.
- 안티 목표: 이미 잘 쓰는 팀(FC키싱구라미 등)에게 불필요한 카드가 계속 보이는 것.

## 접근 (A 선택)
- A. 홈에 체크리스트 카드 (선택) — 기존 데이터로 완료 판단, DB 변경 없음.
- B. 팀 생성 직후 전체 화면 마법사 — 먼저 둘러보려는 사람이 이탈할 수 있어 제외.
- C. 초대 버튼만 키우고 카톡 공유 추가 — 첫 경기까지 이끌지 못해 제외.

## 결정 사항
- 4단계: 팀 이름 정하기(이름이 "우리팀"이 아니면 완료) / 팀원 초대(팀원 2명 이상이면 완료, 카톡으로 보내기 버튼) / 경기 등록(경기 1건 이상) / 포지션 배정(배정 1건 이상).
- 팀장(`is_owner`)에게만 보인다. 4단계 모두 완료하거나 "닫기"를 누르면 사라진다. 닫은 기록은 팀별로 그 기기(localStorage)에만 저장한다.
- "카톡으로 보내기"는 `navigator.share`로 공유 창을 열고, 안 되는 환경이면 링크 복사로 대신한다.
- 기존 "우리팀" 배너는 이 카드의 1단계로 합친다(배너 제거).
- 성과 지표: 새 팀 중 팀원 2명 이상인 팀의 비율(운영 리포트로 확인).

## 빌더에게 남기는 것 (내 판단)
- 경기·배정 개수를 어디서 얻을지(대시보드가 이미 가진 데이터 재사용 우선, 없으면 가벼운 기존 API 활용).
- 카드 세부 디자인(기존 홈 카드 스타일과 맞춘다).
