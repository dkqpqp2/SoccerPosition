# 선수별 AI 코칭 가이드 — 짧은 설계 (승인됨 2026-11-26)

## 의도와 이유
감독·코치가 선수에게 피드백을 줄 때 더 편하게 말할 수 있게 한다.
선수가 직접 정한 희망 포지션과 평가 장단점을 바탕으로, 그 자리에서 해 줄 플레이·피할 것·추천 연습을 AI가 정리하고, 결과를 감독·코치 전용 공간에 저장해 자주 꺼내 보게 한다.

## 목표 / 비목표
- 목표: 선수 한 명당 코칭 가이드 생성·저장·재열람, 피드백 전달 여부 표시.
- 비목표: 팀 전체 전술 분석, 선수 본인에게 공개, 전체 선수 일괄 생성, 가이드 이력 보관.
- 안티 목표: 관리자급 전용 정보(메모)나 이름이 AI로 나가는 것, 선수/일반 팀원이 가이드를 읽는 것.

## 접근
- A (선택): 팀원 관리에 관리자급 전용 "코칭" 탭 + 선수당 가이드 1개 저장(덮어쓰기).
- B: 저장 없이 누를 때마다 생성 — 사용자가 "자주 볼 수 있는 공간"을 원해 제외.
- C: 평가 탭에 같이 넣기 — 평가 탭은 팀원 모두에게 공개라 제외.

## 결정 사항
- 권한: `canManage`(owner/manager/coach/president)만 목록·생성·전달 표시. 일반 팀원은 API가 403.
- 저장: 테이블 `member_coaching_guides`(PK team_id+member_id), RLS 켜고 정책 없음. 입력 지문(`basis_hash`)을 저장해, 희망 포지션·장점·단점이 바뀌면 "평가가 바뀌었어요"로 표시.
- AI 입력: 희망 포지션(1·2지망, 한글 설명 포함)과 장점·단점만. 이름·메모는 보내지 않는다.
- 결과 형식(JSON): play(이 자리에서 해 줄 플레이), avoid(피할 것), drills(추천 연습 3개), talk(대화 포인트). 길이 제한 적용.
- 호출 제한: 전술판 AI와 같은 하루 횟수(`increment_ai_usage`, 팀당 10회, 우리 팀 무제한). 실패 시 차감 복구.
- 모델: 전술판 AI와 같은 `claude-sonnet-4-5`.
- 전달 완료: 가이드별 `delivered_at` 표시/해제. 다시 만들면 전달 완료는 해제.
- 동의: 기존 `useAiConsent` 모달을 생성 직전에 사용.
- 대상 선수: 정규 팀원(용병 제외, `left_at` 없음). 장점·단점이 둘 다 비면 생성 불가.

## 빌더에게 남기는 것 (내 판단)
- 카드·목록 디자인은 기존 평가 탭 스타일에 맞춘다.
- 호출 제한 로직은 새 모듈(`src/lib/aiQuota.ts`)로 두되 기존 전술판 AI 라우트는 건드리지 않는다.
